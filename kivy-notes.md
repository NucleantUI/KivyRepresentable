# Kivy notes

Running notes for the KivyRepresentable experiment. See `plan.md` for the goal,
`progress.md` for the graphics checklist.

## Shape of it

- A Swift app is the host. Python is started from inside it (via
  PySwiftKit) before the Kivy window group comes up — Python never launches
  the app.
- One shared C api, linked by both sides:
  - Swift side (KivyRepresentable): its own shader node, built on
    NucleantVulkan only, the way NucleantSkia ships `SkiaShaderNode`
    (`SkiaShaderNode<ContainerNode>: VulkanSkiaRenderNode: VulkanRenderNode`
    + a `VulkanRenderEngine` extension that makes the engine-owned VkImage).
    It owns the shared VkImage and implements the GL table into it.
  - The view part lives here too, built on NucleantUI as a dependency.
    Build with `swift build --target KivyRepresentable` (and
    `--target CKivyNUI` for the dylib), not a plain `swift build`.
  - **NucleantUI itself is not changed.** Use it as it is; nothing added to
    it. How the node gets hooked into NucleantUI's own rendering is decided
    later (maybe a NucleantUI branch). If something seems to need a
    NucleantUI change, stop and say so; don't make it.
  - Kivy/Cython side: links the same C api and renders into that image.
- Kivy is a singleton (one App, one Window), so one shared shader node is
  enough.

## Ground rules

- **Replace the GPU layer, not Kivy.** Canvas, instructions, vertex/context
  instructions, Fbo, Texture etc. are *not* rewritten. They keep issuing the
  same calls as today; the layer under them (the `cgl` backend / shared C api)
  is what changes, and it renders into the shared image. The more Kivy files
  we touch, the more this experiment fails.
- **What we do change:** the window provider (`_nui`), the clock (ticked by
  DisplaySync), the providers that depend on SDL (text, image, clipboard),
  and provider selection/config so `nui` can be picked. Prefer adding new
  files over editing existing ones.
- **Kivy's orientation is respected: origin bottom-left, y up.** The host is
  top-left, y down. The conversion happens on *our* side, at the boundary,
  never inside Kivy:
  - Input (mouse, touch, scroll): forwarded **unflipped**, top-left, the way
    SDL delivered them. Kivy's own code does the flip, and must keep doing
    it: `window_sdl2.py` `_fix_mouse_pos` (`system_size[1] - 1 - y`), the
    mouse provider's `ny = 1.0 - ny` (`kivy/input/providers/mouse.py`), and
    the SDL touch provider's `y = 1 - y`. Flipping before Kivy would flip
    twice. So "on our side" means: match SDL's coordinates exactly
    (window points, top-left; touches normalized 0…1, top-left).
  - Output: Kivy keeps rendering with its own projection. If the shared image
    comes out upside down in Vulkan, the shader node fixes it when it samples
    the image (flip v). Kivy's matrices are not touched.

## Shared C api — `dependencies/CKivyNUI/include/kivy_nui.h`

- Built by the Swift package (`Package.swift`) as the dynamic library
  `libCKivyNUI.dylib`. The Swift host and Kivy's Cython extensions both
  link that one library, so there is one copy of its state in the process.
- Each side registers a table with it: the host (`kivy_nui_set_host`) before
  Python starts, Kivy (`kivy_nui_set_kivy`) from `_window_nui.pyx`. Exported
  `kivy_nui_*` functions forward to the other side's table.
- GPU (`kivy_nui_gl.h`, generated by `generate_kivy_nui_gl.py` from
  `kivy2x`): Kivy's whole GPU dependency is the `GLES2_Context` table in
  `kivy/graphics/cgl.pxd`, 129 functions. `KivyNUIGL` is that table member
  for member (same names, same signatures, our own type names so it can be
  included next to system GL headers), plus the 299 `GL_*` constants
  cgl.pxd declares as `KIVY_NUI_GL_*`. The host implements the table on
  Vulkan and registers it (`KivyNUIHost.gl`). `cgl_nui.pyx` copies
  `kivy_nui_gl()` into Kivy's table, the way `cgl_angle.pyx` fills it from
  `eglGetProcAddress`. Framebuffer 0 = the shared image. The VkImage never
  shows up in the api.
  - Kivy's shaders: GLSL with no `#version`, `#ifdef GL_ES` precision
    header (`kivy/data/glsl/header.vs/.fs`). Attribute locations are read
    after linking (`glGetAttribLocation`, `shader.pyx:533`).
  - `cgl.pxd` has `GL_ANT_COLOR` / `GL_ANT_ALPHA` (+ `ONE_MINUS_`): a typo
    for `GL_CONSTANT_*` in Kivy itself, no value anywhere, unused. Skipped.
- Input: queued by the host (`kivy_nui_push_event`), drained by Kivy with
  `kivy_nui_poll_event`, the same pull model as `_window_sdl2.pyx` `poll()`.
  So `window_nui.py`'s event handling can stay close to `window_sdl2.py`'s.
  Event types mirror SDL's `poll()` actions (no joysticks); key codes,
  scancodes, `KMOD_*` bits and mouse button numbers are SDL2's, so Kivy's key
  mapping stays as is.
- Clock: the host's DisplaySync callback calls `kivy_nui_tick(dt)` (dt =
  seconds since the previous tick, what `DisplaySync.newCallback` gives).
  Kivy's tick = one pass of its old main loop: poll events, clock, draw,
  `kivy_nui_present` (= `Window.flip`).
- Window commands from Kivy so far: title, system cursor (Kivy's 12 names),
  cursor visibility, show/hide keyboard, request close. Clipboard is its own
  provider, not here yet.
- Status: headers + `kivy_nui.c` (tables, forwarding, event queue)
  written; `Tests/CKivyNUITests` covers them (`swift test --filter
  KivyNUITests`). The GL table itself is not implemented yet.

## Kivy side (in `kivy2x`)

New files:
- `kivy/lib/kivy_nui.pxi`: Cython declarations of `kivy_nui.h`, included like
  `lib/sdl2.pxi`. `KivyNUIGL` members are declared `void *`; cgl_nui casts
  each to Kivy's own pointer type.
- `kivy/graphics/cgl_backend/cgl_nui.pyx`: made from `cgl_angle.pyx`, each
  `eglGetProcAddress("glX")` → `gl.glX` from `kivy_nui_gl()`.
- `kivy/core/window/_window_nui.pyx`: `_WindowNUIStorage`; `poll()` returns
  `_window_sdl2.pyx`'s tuples (wheel and dropbegin carry the cursor position
  SDL's window queried separately). Registers the tick (`set_tick`).
- `kivy/core/window/window_nui.py`: `WindowNUI`, WindowSDL's event handling
  and key maps; the host's tick runs one pass of `EventLoop.mainloop`
  (`EventLoop.idle()` + `mainloop()`); `_finish` does what `runTouchApp` /
  `App.run` did after the loop, then `request_close`. Refuses to start
  without a host, so `core_select_lib` falls through.

Changed in Kivy (originals of replaced functions kept under a `_` name):
- `kivy/clock.py`: `ClockBaseBehavior.idle` no longer sleeps for `maxfps`;
  original is `_idle`. (Default clock only; the interrupt/free clocks keep
  their own `idle`.) This changes the default clock for SDL builds too.
- `kivy/base.py`: `runTouchApp` returns without looping when the window has
  `ticked_by_host`; original is `_runTouchApp`.
- `kivy/app.py`: `App.run` returns without `_stop()` in that case; original
  is `App._run`.
- One-word additions: `'nui'` in `kivy_options['window']`
  (`kivy/__init__.py`), the recognized backends in `cgl_init`
  (`graphics/cgl.pyx`), and `('nui', 'window_nui', 'WindowNUI')` first in
  `window_impl` when `USE_NUI` (`core/window/__init__.py`).
- `setup.py`: `c_options['use_nui']` (`USE_NUI=1`), `determine_nui_flags()`
  (`KIVY_NUI_INCLUDE_DIR` / `KIVY_NUI_LIB_DIR`, default: this package's
  `dependencies/CKivyNUI/include` and `.build/debug`), and the two
  extensions. cgl_nui uses `gl_flags_base`: no system GL is linked.

Build: `swift build --target CKivyNUI`, then in `kivy2x`, with a Python
that has **Cython 3.0.11** (Kivy pins `<=3.0.11`; 3.2 fails on `long` in
Kivy's own .pyx files):
`ARCHFLAGS="-arch x86_64" USE_NUI=1 USE_SDL2=0 USE_GSTREAMER=0
USE_PANGOFT2=0 python setup.py build_ext --inplace`.
`ARCHFLAGS` must match the dylib's arch (this Mac: x86_64); the python.org
Python is universal2 and would otherwise also build arm64, which can't link
an x86_64-only libCKivyNUI.

Test: `python Tests/kivy/test_window_nui.py` (same Python as the build;
needs Pillow for the PIL text provider). It plays the host through ctypes:
an App runs from `kivy_nui_tick`, a click reaches a Button, quit stops the
App and calls `request_close`; and with `KIVY_GL_BACKEND=nui`, Kivy's
`glGetString` / `glClearColor` land in the host's table. The window test
uses Kivy's `mock` GL, since the Vulkan GL table doesn't exist yet.

Run (set by the host before starting Python): `KIVY_WINDOW=nui`,
`KIVY_GL_BACKEND=nui`.

Not done yet: text provider (without SDL Kivy falls back to PIL if
installed), clipboard, image via SDL (macOS has `imageio`).

## Where things live in `kivy2x`

- Window provider (SDL today): `kivy/core/window/window_sdl2.py`,
  `kivy/core/window/_window_sdl2.pyx` → new `window_nui.py` / `_window_nui.pyx`.
- GL function table: `kivy/graphics/cgl.pyx` picks a backend from
  `kivy/graphics/cgl_backend/` (`cgl_gl`, `cgl_glew`, `cgl_sdl2`, `cgl_angle`,
  `cgl_mock`, `cgl_debug`). A `cgl_nui` backend is the natural slot for ours.
- ANGLE reference for "kivy draws into something it doesn't own":
  `kivy/graphics/egl_backend/` (`egl_angle*.pyx`, `egl_angle_metal_implem.mm`).
- Clock: `kivy/_clock.pyx` — `CyClockBase.tick(curtime)`; to be driven by a
  NucleantSync DisplaySync callback instead of Kivy's own loop.

## SDL-dependent files (beyond the window)

From a grep for `sdl2`/`SDL` — each needs a `_nui` provider or must not be
selected:

- text: `text_sdl2.py`, `_text_sdl2.pyx` → Skia-backed text provider
- image: `img_sdl2.py`, `_img_sdl2.pyx`
- clipboard: `clipboard_sdl2.py`, `_clipboard_sdl2.pyx`
- audio / video: ignored for now (per plan)
- provider selection / config: `kivy/__init__.py`, `kivy/config.py`,
  `kivy/base.py`, `kivy/app.py`, `kivy/metrics.py`,
  `kivy/core/*/__init__.py`, `kivy/graphics/cgl.pyx`
